RUPESH'S DIWALI CELEBRATION 2026
================================

QUICK START
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open index.html.
4. Install the VS Code extension "Live Server" if needed.
5. Right-click index.html > Open with Live Server.

YOUR 7 PHOTOS
The photos you supplied are included in photos/ as photo1.jpg ... photo7.jpg.
The slideshow changes every 10 seconds.

500+ WISHES
The Hindi and English wish generator combines original message parts (625+ possible
Hindi combinations and 200 English combinations). Select a language and click
"Generate another wish".

MUSIC
For copyright reasons, no commercial songs are bundled. To add your own music:
1. Click "Choose music files" on the website.
2. Select multiple MP3/audio files at once (you can select 200+).
3. Press Play. Previous and Next controls work through the selected queue.
Use music you own or have permission to use. Browsers require a user click before
playing audio; autoplay with sound is blocked by most browsers.

GITHUB PAGES
1. Create a PUBLIC GitHub repository, e.g. diwali-magic-2026.
2. Upload index.html, photos/ and this README.txt (keep the folder structure).
3. Repository Settings > Pages.
4. Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
5. Wait for the Pages URL to appear in Settings > Pages.

IMPORTANT
Keep the photos folder next to index.html. Do not upload only index.html.
For a public website, everyone who has the link can view the photos.
